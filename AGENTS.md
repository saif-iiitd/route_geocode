# Project handoff convention

Whenever the user asks for a handoff, create or update a Markdown handoff in
`handoffs/codex_handoff_<date>.md`, replacing `<date>` with today's local date in
`YYYY-MM-DD` format (Asia/Calcutta). Include the current objective, completed work,
artifacts, validation, constraints, unresolved issues and next-step boundaries.
Preserve relevant earlier information when updating a same-day handoff.
