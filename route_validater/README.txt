Route Geocoder Validation Map

The ChatGPT sandbox may block HTML pages from running directly in the browser.

Recommended method:
1. Extract this ZIP to a normal folder on your computer.
2. Double-click index.html.
3. Keep an internet connection active. The page loads Leaflet and OpenStreetMap tiles from the web.

If your browser still blocks a local HTML page, serve the folder locally:

Windows / macOS / Linux with Python installed:
  python -m http.server 8000

Then open:
  http://localhost:8000

Run the command from inside the extracted route_geocoder_map_package folder.
